# Tarea 4 - Sistema de Registro y Login con React y Express (en memoria)

## Descripción

Este proyecto consiste en una aplicación web de registro y login de usuarios, desarrollada con **React** en el frontend y **Express** en el backend.  
El objetivo principal es permitir que los usuarios se registren, inicien sesión y mantener su sesión activa mediante el **Context API** de React.  
El backend almacena los usuarios en memoria (arreglo) y valida registros y credenciales de inicio de sesión.

El proyecto está diseñado para ser desplegado en un único servidor, sirviendo tanto la aplicación de React como la API de Express.

Se utiliza **Bootstrap** para estilizar los formularios y la interfaz de usuario.

---

## Tecnologías utilizadas

- Frontend: React, React Router, Bootstrap, Vite
- Backend: Node.js, Express
- Control de estado: Context API (React)
- Despliegue: Render

---

## Funcionalidades

- Registro de usuarios con validación de email duplicado
- Inicio de sesión con verificación de credenciales
- Almacenamiento de sesión mediante Context API
- Interfaz responsiva con Bootstrap
- Backend en Express sirviendo archivos estáticos de React
